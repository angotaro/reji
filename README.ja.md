# Reji（レジ） v0.1.2

**English:** [README.md](README.md)

JPYCで受け取れる、お店のための無料のレジ（Webアプリ）です。お客様はQRコードを読み取って、自分のウォレットから支払います。お金は、お店のウォレットへ直接届きます。登録も、月額料金も、決済手数料もなく、運営のサーバーもありません。

公開サイトは、このリポジトリの右側「About」にあるリンクから開けます。

## できること

- **お会計**：商品をタップするか、テンキーで金額を入れて、QRコードを見せるだけ。入金をブロックチェーンで確かめて「入金済」にします
- **どのウォレットでも**：QRコードはひとつ。HashPort Walletは「コピーして送る」、MetaMaskなどはウォレットのアプリの中で支払えます
- **手数料なし決済（Polygon）**：お客様は署名するだけ。ネットワーク手数料は、お店の「ガス用ウォレット」が払います
- **電子レシートと領収書**：インボイス（適格簡易請求書）の記載に対応。宛名・但し書きは、お客様が自分のスマホで入れます
- **お店のページ**：紹介・SNS・お品書き・出店情報をまとめたページ、はがきサイズの店頭POP、ファンからの応援（投げ銭・任意）
- **端末まわり**：バックアップと引き継ぎ（2台目のレジにも）、ホーム画面に追加してアプリのように使える（PWA）、電波がなくても画面は開きます（支払いには接続が必要です）
- **非常時・オフライン**：インターネットにつながらないときも、お会計の画面は使えます。その場で入金を確かめられないときは「あとで払ってもらう」（後払い）で、商品を先にお渡しして、お客様にはつながったときに払ってもらえます（上限つき。入金はレジが自動で確かめて売上にします）
- **対応チェーン**：Polygon・Avalanche・Ethereum・Kaia（それぞれテストネットあり）

## 使い方

- 公開サイトの「Rejiを無料で始める」から始めます。まずは「テストモード」で、テスト用のJPYCを使って試せます
- スタッフマニュアル（PDF）：[docs/reji-manual-ja.pdf](docs/reji-manual-ja.pdf)
- 公開サイトには、「使い方のアイデア」（取り置き、出張、2台目のレジなど）と、「バックアップと引き継ぎ」のページもあります

## 自分で公開する（無料）

GitHubとCloudflare Workersを使って、無料で公開できます。くわしい手順は [docs/DEPLOY.ja.md](docs/DEPLOY.ja.md) にあります。

- ビルドコマンドは `node tools/build.mjs`、デプロイコマンドは `npx wrangler deploy`、ビルド変数に `SITE_URL`（公開アドレス）を入れます。`OPERATOR_NAME` と `CONTACT` は任意です
- 公開アドレス（workers.dev のサブドメインなど）に、jpyc・metamask・hashport・wallet などのブランド名を入れないでください。ウォレットの詐欺サイト判定で警告が出ることがあります

## しくみ

- **サーバーなし**：静的なサイトと、公開ノード（RPC）と、Nostrリレーだけで動きます。運営のデータベースはありません
- **お金を預からない**：お金はお客様のウォレットからお店のウォレットへ直接移ります。運営は、お金にも鍵にも触れません
- **データはお店の端末の中**：設定・商品・売上は、お店の端末のブラウザに保存されます。アカウント登録はありません
- **入金の確認**：金額に付けた「目に見えない端数」で注文を見分け、2つ目の公開ノードでも同じ送金を確かめます
- **署名つきのお店のプロフィール**：受取アドレスも含めて署名しているので、プロフィールと受取先が合わないリンクでは支払えません
- **トラッキングなし**：Googleのサービスや解析タグは使っていません

各機能のくわしいしくみは、英語の [README.md](README.md) にあります。

## ほかのサービスとの連携（開発者向け）

リンクでお支払いページを開き、入金はブロックチェーンで確かめるだけです。APIキーも、サーバーも要りません。

- 連携ガイド（日本語・English）：[docs/INTEGRATION.md](docs/INTEGRATION.md)
- 多数の注文・複数のお店をまとめて照合する参考実装（テストつき）：[docs/examples/order-matcher.mjs](docs/examples/order-matcher.mjs)

## セキュリティ

## 開発とテスト

```sh
python3 -m http.server 8080        # プロジェクトのフォルダで
node --test                        # ユニットテスト（61）
npm i -D playwright && npx playwright install chromium
node tests/e2e.mjs                 # E2Eテスト（174項目。スクリーンショットは tests/shots/）
node tests/devices.mjs             # スマホ・タブレット13機種 × 11画面
node tests/offline-workers.mjs     # Workers の .html 転送のもとでのオフライン起動
python3 manual/images.py           # スタッフマニュアルの画像を作る（tests/shots/ から）
node manual/build.mjs              # スタッフマニュアルの元データ（manual/）から docs/reji-manual-ja.pdf を作る
```
